# Project rules
- Department splits update existing staff profiles by exact case-insensitive email matches; preserve assessment and completion data because achievements belong to staff, not departments.
- Keep legacy departments selectable until unassigned staff are resolved; reporting uses current staff-profile departments and must retain existing export contracts.
- Staff levels export uses a server-validated read-only admin RPC, existing dated progression events and attributable staff activity; never infer activity from profile updates or admin imports. Reuse Journey task builders so Teams and Forms count once per level.- Staff levels export row logic lives in supabase/functions/_shared/staffLevelsCore.ts and is shared by the admin download and the token-protected staff-levels-export function, so both always return identical rows.
